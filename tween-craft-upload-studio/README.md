# 🎭 Custom Uploads Animation Studio

استوديو أنيميشن محلي يعتمد على رفع المستخدم لصور أجزاء الشخصية الـ 12 بشفافية (PNG)، مع هيكل عظمي متصل، سحب مباشر، وتسجيل فريمات سلس.

## التشغيل:
1. قم بتشغيل خادم محلي (مثل Live Server أو Vite).
2. ارفع صور الأجزاء الخاصة بك من القائمة الجانبية.
3. اسحب الأطراف مباشرة على الشاشة وحرك الشخصية!
